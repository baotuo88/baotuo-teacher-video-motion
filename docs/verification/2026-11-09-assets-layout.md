# 素材与编辑布局增量验收

## 本轮交付

- 图片 PNG/JPEG/WebP：20MB、1600万像素限制，解码重编码为 PNG，去除元数据，生成缩略图。
- 配音 WAV：16-bit PCM、1/2声道、8–96kHz、0.2–120秒，规范化保存。
- 素材列表、搜索/筛选、试听、归档；归档不物理删除历史引用。
- 分镜图片/WAV绑定，保存时检查类型和存在性；提交时检查逐页配音完整性。
- 渲染时SHA-256核验、复制素材至独立任务目录；按真实音频时长调用引擎生成字幕。
- SQLite v1→v2增量建表与未来版本拒绝启动。
- 编辑器宽内容区、分组设置栏、固定保存工具栏、分镜导航、素材弹窗、移动端纵向布局。
- 将原压缩式前端文件格式化，便于后续修改和审查。

## 限制

尚无SVG/GIF安全上传、MP3解码上传、自定义图片/语音API、完整Skill执行器；归档不释放磁盘，仍需后续物理清理/配额。上传接口限制单文件而非总库存。当前真实素材渲染在本机完成，非Docker完整渲染验收。此次未调用付费服务，未把测试音称为真实配音。

旧镜像没有数据库未来版本门禁，不应直接连接升级后的数据库；升级前备份，旧版回退需恢复相应备份。
