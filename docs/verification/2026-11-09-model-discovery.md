# 自定义服务模型发现验收

## 功能

- 未保存的地址/Key可直接查询模型，无需先填写模型名保存。
- 已保存配置通过provider_id引用加密Key，不将Key发回前端。
- Base URL改变后拒绝沿用旧密钥；保存配置也要求新地址重新提供Key。
- GET /models，解析data[].id，校验、过滤、去重排序；搜索选择，保留手动输入。
- 后端不跟随重定向、不自动重试；20秒连接/读超时，2MB响应限制，最多5000条。
- 认证、无权限、404/405、限流分别提示；不返回远端错误体。
- UI在连接字段变化后丢弃过期响应，刷新列表不覆盖当前模型。列表不能作为聊天能力的证明。

## 验证

83项pytest通过，包括上轮素材测试；新覆盖草稿不持久化、GET请求、保存Key引用、新地址拒绝旧Key、解密失败、无效格式、超大响应、HTTP错误脱敏、DNS私网拒绝、认证/CSRF。

scripts/browser-models.cjs实际操作登录与模型服务界面，mock列表及保存响应：选择模型、搜索、401后手动填写、引用旧Key、保留已选模型、异步过期响应被忽略全部通过。1440与390宽度截图检查，无横向溢出/JavaScript错误。截图在.data/e2e/models-*.png，不发布。

仅mock验收，未调用真实外部模型或付费API。官方模型列表文档访问受阻，不能把未读取的文档作为已验证兼容性的依据。当前只支持已声明的常见兼容格式，不声称支持所有服务商或所有分页协议。

本轮新增代码仍在本地工作区，未提交或推送；GHCR镜像不会因本地修改自动更新。
