# 制作配置、结果列表和媒体确认状态修复

## 范围与原因

本轮完成整体检查计划的前三项；未宣称完成全部上线优化。

1. `openProject` 原来重新初始化音轨为 silent，造成重进项目丢失选择。
   新增按项目保存的制作设置（音轨、Edge 音色、文本模型服务 ID），独立 CAS 版本，不影响分镜确认与在途生成快照。
   前端串行保存，显示保存状态，重新进入读取服务端；失败/并发冲突明确提示并阻止提交制作，不自动覆盖远端设置。
   保存的服务失效时提示重新选择，不偷偷替换供应商。
2. `renderJobs` 原来完整重建列表，无关任务变化也替换播放器。
   改成按任务 ID 和内容签名复用卡片，不移除或重新插入顺序未变化的播放器；已展开日志保持。
3. 媒体自动应用原来和生成分镜一样清空确认状态。
   现在仅当源版本已确认且仍为当前版本，图片/配音自动绑定后延续确认。
   新分镜生成、修改口播等普通编辑仍清空确认；版本冲突仍保留结果、不覆盖。
   这不是对生成图片/语音质量的自动批准，仍需查看/试听检查建议。
