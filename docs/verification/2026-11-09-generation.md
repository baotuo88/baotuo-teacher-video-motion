# 三类能力与逐页生成验收

## 实现

Provider新增storyboard/image/speech类型，兼容旧配置默认为storyboard。可复用同地址的加密Key副本；新地址拒绝复用。图片尺寸、语音音色/语速字段。三类能力概览、动态表单、逐页生成确认弹窗、结果预览/试听与应用。

任务类型image/speech，固定来源项目版本和配置更新时间。产物入库并记录来源，应用前严格版本比较，阻止重排/新稿被覆盖。远端超时/5xx标记unknown_outcome，无自动付费重试。恢复仍采取interrupted人工检查策略。

图片协议/images/generations，支持base64/URL；语音/audio/speech，返回音频经FFmpeg转WAV。URL下载独立检查且不转发API Key。

## 验证结果

- 98项pytest通过；覆盖能力筛选/复用Key、安全URL/重定向、超时状态、图片/语音任务、音频规范化、应用冲突、确认费用门禁。
- 浏览器mock验证三类配置、音色/语速保存、复用密钥、图片/语音逐页对话框；1440/390布局无溢出，无pageerror。
- 脚本generation-smoke.py：模拟文本/图片/音频远端响应，真实调用本地API、Store、Worker、Asset和Frametell，完成分镜→图片→音频→审核应用→MP4/SRT。
- 产物工作区 `.data/e2e/generation-165cae4a`，任务`254466ee3e394f2e8046c0c20573a2cb`，1920×1080、12fps、5.7秒，有/无字幕MP4、SRT、预览PNG。
- 音频是3秒440Hz测试音，非真人人声。没有真实供应商调用或付费。
