# 横向分镜条滚动位置修复

复现：20页模拟项目，1440px宽度，滚动并点击第16页，scrollLeft从2086回到0。
根因：单页模式点击调用renderEditor，重新创建横条DOM，丢失scrollLeft。

修复：
- 点击分镜只切换卡片显隐和选中标识，不重建编辑器或重连任务流。
- 项目内记录滚动位置；必要的重绘后恢复，并最小幅度调整以保证选中项可见。
- 换项目重置横条位置；切换制作阶段保留位置。
- 查看全部模式仍滚动到对应分镜，选中标识同步更新。

验证：browser-scene-scroll在改动前失败，改动后通过；涵盖storyboard/media、1440/390宽度、查看全部再回单页。
browser-studio完整阶段/自动应用/未保存编辑回归通过。测试使用模拟项目，没有修改真实项目或调用生成服务。
