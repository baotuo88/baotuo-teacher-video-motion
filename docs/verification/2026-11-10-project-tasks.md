# 项目内任务、实时日志与删除

## 行为

- 分镜、图片、配音、视频任务提交后留在项目内，滚动到任务区，不再跳转全局列表。
- SSE 向已登录客户端推送该项目最近100个任务快照，最近20个任务各自最近200条阶段日志。
- 当前实现是任务状态/阶段日志实时更新，不是模型逐 token 输出，也不直接转发未经脱敏的子进程日志。
- 后端每秒检查变化，无变化发送心跳；约50秒关闭一次让浏览器重连、重新验证登录。重连发送当前快照，因此不依赖旧事件游标。
- 离开项目、退出登录或重新加载编辑器会关闭旧流；日志更新不会替换分镜表单或未保存输入。
- 日志与生成分镜结果使用独立区域；结果下载、取消、重试、应用仍使用既有安全校验和计费确认。
- 删除需要二次确认、当前项目版本、认证与CSRF。SQLite事务与入队互斥，有queued/running任务时返回409。
- 删除项目和编辑历史不可撤销。共享素材、任务快照与成片保留，因此不是磁盘清理，也不保证隐私数据擦除。
- 删除后旧任务不可再应用到该项目或提交新重试；全局列表仍保留任务和下载。

## 验证

- 后端142项测试通过，包括删除权限/确认/版本/活动任务防护、保留任务快照、项目隔离、SSE日志变化与删除事件。
- `browser-project-tasks.cjs`：模拟项目验证留在项目提交、实时日志、编辑保留、删除取消与确认、流关闭，以及1440/390无横向溢出。
- `browser-capabilities.cjs`、`browser-workspace.cjs` 通过，无付费请求，无真实项目删除。
- 本地真实登录接口 `/api/projects/{pid}/events` 返回HTTP200、text/event-stream、snapshot事件及任务日志。
