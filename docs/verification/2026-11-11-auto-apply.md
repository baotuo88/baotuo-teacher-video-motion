# 生成结果自动应用与建议审核

- 新提交的分镜/图片/语音任务在快照中固定 auto_apply=true；旧任务继续遵循原有手动应用语义，不追溯覆盖已有项目。
- Worker 在同一SQLite事务中校验项目版本、生成新草稿/历史版本、记录任务成功与应用状态。重复完成不重复加版本，取消后不应用。
- 已有版本变化则任务仍成功、结果保留、application=conflict；不覆盖人工改稿，不自动重新调用模型。
- 自动应用清除分镜确认状态。付费确认、最终分镜确认及手动提交渲染保留，不自动产生额外付费任务。
- review为本地规则：重复标题、空要点、长口播、长要点与人工检查提示。不会声称事实正确、图片合规或语音质量达标，不调用额外AI。
- SSE识别自动应用后只在本地无未保存修改时更新项目，不切换阶段、不重置页码/音轨。异步素材加载后再次检查页面和版本，避免覆盖输入。
- 有未保存修改时保留页面文本，明确提示服务器新版本；保存仍受乐观锁保护。人工可复制保留文字后重新打开项目处理。
- 结果页面隐藏已自动应用任务的手动应用入口；旧结果仍可手动应用，冲突图片/配音仍可从素材库选择。
