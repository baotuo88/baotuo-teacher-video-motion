# 文本、图片、语音服务与制作流程设计

项目：baotuo-teacher-video-motion
日期：2026-11-09
状态：**设计提案，尚未实现**。本轮只修改设计与术语，不新增业务能力。

## 1. 核心决定

采用「服务连接 → 能力配置 → 项目制作配置」三层设计。

- **服务连接**保存地址、协议与凭据；同一服务地址可供多种能力复用，不重复填写 Key。
- **能力配置**分别指定文本、图片、语音模型及参数；同一个模型能承担多个能力，但必须分别适配和验证。
- **项目制作配置**选择本项目所用能力配置，允许逐页覆盖图片/音色，实际提交时冻结解析结果。

不强制要求3个模型/3个Key/3个账号。手动分镜+自备素材音频可以零模型；文本模型+自备素材可以只配一个；全自动辅助制作一般配置文本、图片、语音3种能力。

本提案暂按现有单管理员、单工作空间设计，不引入多租户、任意HTTP模板或供应商脚本执行。

## 2. 能力定义及边界

| 能力标识 | UI名称 | 输入 | 产物 | 未配置时 |
| --- | --- | --- | --- | --- |
| storyboard | 文本分镜 | 主题/受众/时长/已选Skill参考 | 校验后的分镜结构 | 手动编写 |
| raster_image | 图片生成 | 本页画面说明/风格/画幅 | PNG/JPEG/WebP，规范化入库 | 手动上传 |
| speech | 语音合成 | 本页口播/音色/语速/语言 | 音频规范化为WAV及真实时长 | 上传WAV、选择Edge、静音预览 |
| vector_svg（后续） | 矢量图解 | 图解说明 | 安全清洗后的SVG | 不显示生成功能 |
| motion_clip（后续） | 局部动效 | 动效说明 | 经过检查的帧序列 | 不显示生成功能 |

第一批交付前三项。普通图片不伪装成SVG逐笔生长；GIF/视频不与普通图片共用隐含协议。Edge是内置在线语音后端，不要求个人Key，也不宣称完全离线或永久可用。

## 3. Web信息架构

侧栏保持：视频项目 / 素材库 / 制作任务 / 模型服务 / Skill运行时。

模型服务页顶部采用三个标签：

1. **能力与默认值**：文本/图片/语音三张配置卡，查看默认能力配置及验证状态。
2. **服务连接**：维护地址和凭据，获取模型，查看连接使用情况。
3. **测试记录**：列表读取/样例生成记录；仅保存脱敏结果、时间、耗时和可授权访问的产物，不存Key或原始错误响应。

不要在导航栏额外堆三个「模型后台」。非管理员未来只能看可用能力，不获得连接凭据权限。

```text

[能力与默认值] [服务连接] [测试记录]

┌ 文本分镜 ─────────┐ ┌ 图片生成 ─────────┐ ┌ 语音合成 ─────────┐
│ 默认：讲解编导     │ │ 默认：白板插画     │ │ 默认：中文讲解     │
│ 连接A / 模型X      │ │ 连接A / 模型Y      │ │ 连接B / 模型Z      │
│ 状态：样例通过     │ │ 状态：未验证       │ │ 状态：样例通过     │
│ [配置] [运行样例]  │ │ [配置] [运行样例]  │ │ [配置] [试听]      │
└───────────────────┘ └───────────────────┘ └───────────────────┘

当前可用流程：AI分镜 ✓    AI图片 待验证    AI配音 ✓
说明：未配置能力不影响手动编辑和使用上传素材。
```

- ≥1280px三列；900–1279px两列；窄屏单列。卡片内固定字段顺序，不靠大量徽章堆叠。
- 配置采用有标题的抽屉/弹窗；长内容内部滚动、底部操作区可见。手机近全屏，保留显式关闭与未保存提示。
- 状态必须带文字，不能只用红绿颜色。键盘可操作；对话框焦点限制及关闭后恢复焦点。

### 3.2 服务连接表单

基础项：连接名称、协议适配器、Base URL、API Key、启用状态。

高级项默认折叠：超时、并发上限、提供商专属但受限的参数。第一批不开放任意请求头、任意路径、脚本和JSON表达式。

流程：填写连接 → 点击获取模型 → 搜索/选定 → 建立能力配置。允许获取失败后直接手填，自动获取不等于自动保存。

模型列表最长260–320px内部滚动。显示来源时间和「供应商未声明能力」提示；不根据名称包含image/tts就断定能力。若供应商返回可信能力字段由Adapter解析，显示「供应商声明」，实际样例成功另显示「本平台已验证」。

同一连接读取的列表缓存不含Key；缓存按连接版本隔离，有显式刷新。草稿列表仅在当前表单内保存，改地址/Key就失效，旧请求结果不能覆盖新表单。

### 3.3 三类能力配置表单

共同：名称、连接、模型（搜索/手填）、是否设为该能力默认、验证状态。

- 文本：分镜页数范围、语言；温度/输出长度只有适配器支持才显示。模型输出仍严格校验，不执行任意代码。
- 图片：风格预设、比例、尺寸/质量、每次张数（初始限制1张）。供应商不支持的选项不展示；画面文字优先由本地渲染器绘制，不依赖生图写字。
- 语音：模型、音色、语言、语速。音色获取依赖具体协议；列表接口不可用则可手填音色ID。音色与模型的兼容性需实际试听验证。

按钮区分：

| 按钮 | 行为 | 费用提示 |
| --- | --- | --- |
| 获取模型 | 只读取模型清单 | 不生成内容，第三方计费规则自定 |
| 保存配置 | 本地保存并加密 | 不调用外部服务 |
| 运行样例 / 试听 | 真实小规模生成 | 二次确认可能计费，并显示测试文字/图像提示 |

不提供含糊的「连接成功」绿灯：模型列表可用、文本样例成功、图片样例成功、语音样例成功是独立证据。

## 5. 完整制作流程与费用控制

1. 输入主题 → 选择文本能力配置 → 明确触发分镜生成。
2. 查看/修改分镜 → 用户确认当前版本。
3. 选择图片与配音策略：上传、生成、混合；未配置某能力则只禁用对应生成操作。
4. 点击「生成缺失素材」，先出现计划：页码、执行能力、所用模型、数量、预计字数；只计算能确定的统计。
5. 用户确认 → 后台分阶段执行；每页成功立即保存产物，不因别页失败丢失。
6. 审核图片、试听配音；不满意按页重做，旧素材保留为历史版本。
7. 生成低成本预览 → 确认 → 本地渲染与下载。

费用未知显示「供应商价格未知」，不编造人民币估算。仅有可靠价格配置时显示带时间/来源的估算；最终账单以服务商为准。可以限制调用次数、最大页数、图片张数、语音字符数，但不能把这些限制称为精确金额封顶。

「生成缺失」默认不替换已上传/已审核素材。用户选择强制重新生成时明确提示会覆盖选择并可能收费；产物本身仍保留版本。

## 6. 变更与版本语义

- 修改口播：已有自动配音标记「需更新」，不要静默替换。若为上传配音，标记需人工核对，不假装能推断内容一致。
- 修改图片提示词/风格：对应自动图片标记「需更新」；仅改标题不必无条件重生所有图片。
- 新生成任务绑定来源project revision与稳定scene ID。现有仅有场景数组索引，需要新增稳定ID，防重排后把结果写到另一页。
- 任务期间用户编辑：结果保留，应用前比较页面ID和内容摘要；不覆盖新稿，显示「基于旧版本生成」。允许显式选用旧结果而非自动替换。
- 默认配置优先级：逐页覆盖 > 项目指定 > 全局默认。提交时解析一次，冻结配置版本、参数、模型和运行时；以后改默认不改变排队任务。
- Key不写任务快照。服务地址/协议版本不可变，引用版本化的加密凭据；禁用/撤销凭据后未执行任务应暂停待处理，而不是改用别家服务。
- 系统不静默换模型、换服务或降级为静音。任何降级必须得到明确选择。

## 7. 数据结构与模块

### 数据模型（建议新增，非已存在）

| 实体 | 主要字段 |
| --- | --- |
| ServiceConnection | id、名称、当前revision、enabled |
| ConnectionRevision | connection_id、revision、adapter_type、base_url、credential_ref、超时/并发 |
| CredentialVersion | id、密文、归属连接/目标地址、状态、created_at（不回传明文） |
| CapabilityProfile | id、名称、能力类型、当前revision、enabled |
| ProfileRevision | profile_id、revision、connection_revision、model、受限参数、schema_version |
| WorkspaceDefaults | capability → profile_id |
| ModelCatalog | connection_revision、列表/能力声明、fetched_at、过期时间（不证明实际能力） |
| ValidationRecord | profile_revision、测试类型、状态、错误分类、产物ID、时间 |
| GeneratedAssetProvenance | asset_id、任务ID、scene_id、输入摘要、profile_revision、runtime_id、供应商request_id |

沿用资产不可变及归档语义；用关联表保存生成来源，不修改历史素材字节。

### 深模块设计

- **Provider Module Interface**：discover(connection)、validate(profile, explicitConsent)、execute(profileRevision, input, idempotencyKey)。Implementation内部隐藏凭据解析、协议、错误归类、轮询与返回规范化。一个HTTP格式不能伪装成所有供应商均兼容。
- **Production Module Interface**：plan(projectRevision)、submit(plan, consent)、applyResult(task, expectedRevision)、cancel(task)。Implementation负责缺失判断、页级任务、输入摘要、变更冲突和计费不确定性。
- **Asset Module Interface**：ingest(bytes, provenance)、get(id)、archive(id)。Implementation处理下载/解码/清洗/转换/内容哈希。
- **Runtime Module Interface**：inspectCompatibility(runtime, profiles)、activateVerified(runtime)。只管理平台能力与运行时契约，不把Skill文本视作可自动执行的扩展代码。

真实变化处设置Seam：文本与图片/语音协议Adapter；用户上传音频与在线合成音频Adapter。参数Schema由平台Adapter拥有，拒绝任意动态执行逻辑。

### 目标接口草案

- GET/POST /api/connections；POST /api/connections/{id}/revisions
- POST /api/connections/models/discover（支持草稿和已保存连接）
- GET/POST /api/capability-profiles；POST /api/capability-profiles/{id}/validate
- GET/PUT /api/settings/capability-defaults
- POST /api/projects/{id}/production-plan
- POST /api/projects/{id}/production-tasks（plan digest、用户确认、幂等键）
- POST /api/jobs/{id}/apply（expected revision/scene digest）

先保留现有/api/providers作为兼容层，不直接删除影响已有前端。新字段含revision且所有修改均做乐观锁。

## 8. 外部调用与安全

- Key仍认证加密；主密钥与数据库分离备份，日志/错误/素材/导出不携带凭据。
- 地址变更不能沿用旧Key；即使同域更换API前缀也需确认凭据。只有同一连接相同目标可自然复用。
- 保留公网HTTPS、DNS校验、IP绑定、响应大小限制及禁止默认重定向；私网接入另设管理员授权机制，当前不开放。
- 图片服务返回URL必须作为新的下载请求检查SSRF。**不把生成API的Authorization带到图片CDN地址**。默认拒绝私网、重定向和非HTTPS；确需授权下载由特定Adapter实现。
- base64输出同样限大小、验证类型，不能信任Content-Type/扩展名。音频转换用独立受限进程、参数列表、不用shell。
- SVG/GIF后续走专用安全流程：脚本/事件/外链清理、帧数/尺寸/总解码资源限制、确定性时间轴；未完成前不开放。
- 远端已提交但超时：标记unknown_outcome，有request_id先查询；不支持查询/幂等时人工确认后重试，不能自动重复扣费。
- 取消本地任务不保证远端停止计费；UI必须告知，按Adapter能力尝试远端取消。
- 供应商鉴权失败不重试；限流可以提示后再试，付费生成的自动重试只在供应商有可靠幂等契约时允许。

## 9. 跟随上游Skill更新

能力配置独立于Skill版本，不因升级丢失Key。任务仍固定Skill+引擎+Adapter版本。

候选版本检查新增/删除的脚本与产物契约，列出所需能力：已有可满足、缺少配置、需要平台适配。禁止从SKILL.md自动推断新协议后执行任意代码或自动安装供应商插件。

示例：新Skill要求SVG时，图片模型只有PNG能力 → 后台显示「缺少矢量图解支持」，保留旧运行时/现有工作流，而不是静默拿PNG代替SVG。

## 10. 迁移路径

当前providers记录混合了连接、Key和文本model；将每条映射为一个连接+一个文本能力配置，保留原ID映射，不自动跨记录合并同地址的Key。

- 数据库显式版本迁移（现有本地schema v2）；事务执行，先备份，重复启动不重复创建配置。
- 原项目没有能力配置时，保持当前上传/Edge/静音流程；不自动触发生成。
- 不自动把第一条服务设为全局默认，提示管理员选择；默认值变更只影响以后任务。
- 旧任务保持原snapshot及执行兼容路径；新任务使用revision解析。
- 先新增稳定scene ID并为历史版本建立映射；历史快照原样保留，不能原位篡改。
- 初期取消“配置修改导致排队任务直接失败”的现实现，改为锁定配置revision；凭据撤销例外。

## 11. 实施顺序与验收

### A：配置系统

连接/能力配置分层、迁移、全局默认、模型发现、多状态验证UI。验收：同一连接可建多个能力配置，改默认不改变排队任务，换地址不会泄露旧Key。

### B：语音闭环

优先完成一个明确的HTTP语音协议Adapter，因为已有WAV管线；支持音色/语速、逐页合成、试听、实际时长字幕。现有Edge与上传保持兼容。验收：两种音色、重做单页、文本变更标记、失败不误写成功、非WAV返回正确转换。

### C：图片闭环

实现一个明确图片协议Adapter，覆盖base64/URL结果及安全下载；生成图片入现有素材库，逐页选择、重新生成、历史版本保留。验收：单页生成、不替换已上传素材、下载SSRF拒绝、巨大文件拒绝、生成期间编辑不被覆盖。

### D：编排与升级

缺失素材计划、逐页进度、unknown_outcome恢复、上游能力兼容报告。验收真实Docker环境从主题到有声成片，容器重启不重复付费，旧任务版本可追溯。

### UI验收矩阵

1440/1280/1024/768/390宽度；长服务名称/模型ID、5000模型、0模型、禁用服务、401/429、弹窗内错误、键盘导航、未保存离开提醒。关键动作保持可见，不让长模型列表/媒体播放器撑开页面。

## 12. 不是本轮承诺

本轮是设计，尚未实现上述三能力配置系统。当前可用的仅是已有文本Provider、模型发现、上传素材/WAV和受控渲染。具体供应商、模型型号、价格不在本设计中硬编码，真实适配需其实际协议和已授权测试。
