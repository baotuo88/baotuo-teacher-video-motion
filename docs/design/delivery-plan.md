# 完整产品与持续跟随上游的交付范围

## 产品目标

这是长期维护的完整 Web 产品，而非仅展示界面或固定模板的演示。沿用 web-workbench.md 的项目、配置、队列、版本、素材与渲染设计，并以 ADR-0001 修正“固定模板为唯一制作方式”的限制。

## 版本更新契约

- 平台版本：Web、后端、数据迁移、适配器版本。
- Skill 版本：原仓库完整 commit；SKILL.md 的显示 version 不作为唯一身份。
- 引擎版本：独立完整 commit；禁止跟随浮动 main 安装。
- 每个制作任务保存 runtime ID；激活只影响以后提交的任务。
- 文档/提示词变更：在受控执行器中读取候选版本文档，经验收后启用。
- 新增脚本参数/服务商能力：标记需要适配，不能声称自动兼容。
- 依赖或系统组件变更：重新构建/准备运行时，必要时更新 renderer 基础镜像。
- 自动检测不自动执行未知上游代码；管理员批准准备候选版本，真实验证后才可激活。
- 回滚仅切换新任务的默认版本，不覆盖旧项目；数据库迁移不通过 Skill 回滚处理。

## 交付清单（持续更新，不将计划视为已完成）

- [ ] 安全登录、会话、权限和初始化
- [ ] 完整项目/分镜/页面编辑器
- [ ] 模型、素材、语音提供商加密配置与实际适配
- [ ] 受控 Skill 执行器：读取文档、编写项目、审阅、调用有限工具
- [ ] 素材上传、清洗、管理与试听
- [ ] 独立异步任务、实际取消、失败恢复与付费请求去重
- [ ] 真实预览、增量渲染、有/无字幕 MP4/SRT 导出
- [ ] 上游版本检查、锁定、候选验证、激活、回滚
- [ ] Docker Compose 部署与启动验收
- [ ] 测试、备份恢复、安全审查与运维文档

完整产品不以“网页能打开”验收；必须完成从主题到成片、重启恢复、版本更新和回滚的端到端验证。开发阶段的运行时基础设施不冒充完整产品。

## 2026-11-09 实施进度

已落地的单机 Alpha 子集：会话登录/CSRF、项目与分镜编辑、复制/历史恢复、加密自定义聊天配置、分镜生成结果审阅应用、单 Worker 持久化队列、取消/重试/中断保护、静音/Edge 配音接线、受控页面编译、真实本机多页 MP4/SRT 导出、原版本化运行时接入。

当前前端为原生模块化 JS/CSS，暂未引入 React 构建链；队列使用 SQLite 单机事务而非 PostgreSQL/Celery，具体限制见 ADR-0002。原清单保持未勾选，直到对应完整范围达到验收，而不以 Alpha 子集冒充完整完成。
