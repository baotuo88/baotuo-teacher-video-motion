# 更新记录

以下为当前开发版本的用户可见更新；是否可通过镜像使用，以 README 中对应版本的发布状态为准。

### 2026-11-12

- 在项目内完成创作要求、分镜编排、图片与配音、导出视频和结果查看，支持桌面与手机布局。
- 分镜、图片和配音生成成功后安全应用，附带检查建议；有冲突时保留结果和本地编辑。
- 每个项目记住音轨、在线配音音色和文本模型选择，保存失败时明确提示。
- 图片和配音应用后延续已确认的分镜状态，修改讲解内容时重新确认。
- 草稿支持与服务器版本对比、导出和另存；保存期间继续输入的内容得到保留。
- 历史制作记录支持继续加载，任务日志支持完整阅读和下载；实时刷新保留已有播放器与日志面板。
- 删除项目进入回收站，可恢复编辑历史、制作配置和成片入口；活动任务期间提供拦截保护。
- 模型列表和生成请求的网络故障提供更具体的诊断；可能产生费用的请求需要核对后手动重试。
- 分镜横条保持当前页面和滚动位置，手机端可以连续切换靠后的页面。
