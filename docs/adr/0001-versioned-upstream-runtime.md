# 上游 Skill 作为版本化运行时，不维护长期源码分叉

状态：accepted。

本项目需要持续吸收原 Skill 的功能，因此不把上游源码直接改造成 Web 后端，也不将固定页面模板作为唯一执行方式。Web 控制平面与 Skill 执行运行时分离；每个运行时绑定 Skill commit、引擎 commit、适配器版本和依赖锁文件。上游源码按版本原样保存，平台差异在适配器中处理。

更新分为发现、静态契约检查、依赖准备、真实冒烟渲染、管理员切换；运行中任务固定版本，旧版本保留用于重现和回滚。静态检查通过不等于兼容，不能直接激活。自动读取新文档也不等于自动支持全部新功能：新增脚本参数、服务协议或界面操作仍需适配和测试。

后续完整 Skill 执行器可以使用其文档指导代码创作，但只允许在受限运行环境内通过受控工具操作项目，不能给模型 Docker socket、宿主机 shell 或管理密钥。结构化模板作为可靠模式保留，而非上游能力上限。
